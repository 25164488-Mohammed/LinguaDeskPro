## 3. ما تم اختباره فعلياً وما يحتاج إلى بيئة Windows أصلية
1. **ما تم اختباره وتشغيله فعلياً في بيئة البناء:**
   - بناء وفهرسة قاعدة بيانات `SQLite 3 + FTS5` الكاملة (`7,345` مدخلاً، `7,375` معنى، `1,230` تعبيراً اصطلاحياً، `270` جملة مرجعية).
   - البحث المعجمي ثنائي الاتجاه، والتطبيع العربي (إزالة التشكيل وتوحيد الهمزات وتحليل السوابق واللواحق)، وفصل المعاني المتعددة للكلمات المشتركة (`run`, `bank`, `set`, `عين`, `حكم`, `عقد`).
   - البحث التقريبي (`Fuzzy Search`) وتصحيح الأخطاء الإملائية (`algorthm -> algorithm`).
   - ترجمة الجمل والفقرات الطويلة والنصوص المختلطة دون اتصال بالإنترنت في الاتجاهين (`EN ↔ AR`).
   - استخراج النص الفعلي من صورة الاختبار الثنائية (`sample_bilingual_ocr_card.png`) عبر محرك `Tesseract OCR` المحلي وترجمته.
   - نظام المراجعة بالتكرار المتباعد (`SM-2`) وتصدير واستيراد المفردات (`CSV / JSON`).
   - محاكاة التقاط الحافظة الآمن مع التحقق من استعادة محتوى الحافظة الأصلي للمستخدم.
   - التحقق من سلامة الموارد عبر بصمات `SHA-256` وحماية القاموس الأساسي من الحذف.
2. **ما يعتمد على نظام التشغيل Windows عند تشغيل المستخدم للحزمة:**
   - تسجيل اختصار النظام العام على مستوى Win32 (`user32.dll RegisterHotKey`) وتشغيل أصوات `Windows SAPI5` المدمجة واستضافة نافذة `WebView2` أو توليد `LinguaDeskPro.exe` عبر مترجم ويندوز المدمج `csc.exe` (يتم تلقائياً عند نقر المستخدم على `RUN_LINGUADESK_PRO.bat`).
