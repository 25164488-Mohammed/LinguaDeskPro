## نبذة عن المشروع (Overview)

تطبيق **LinguaDesk Pro v7.0 Ultimate** هو تطبيق سطح مكتب متكامل لنظام Windows 10/11 صُمم ليجمع بين القوة الكاملة للعمل المحلي بدون إنترنت (**100% Offline-First**) والترجمة العصبية السحابية الحية عند الاتصال بالشبكة، داخل **ملف تنفيذي واحد مستقل (`.exe`)** يضم بداخله القاموس الشامل، ومحركات المسح الضوئي البصري للصور، والأوزان العصبية، ونظام النطق الصوتي، والنافذة العائمة الفورية فوق جميع البرامج.

## المميزات الرئيسية في الإصدار السابع (Key Features in v7.0)

| الميزة | التفاصيل التقنية والوظيفية |
| :--- | :--- |
| **معجم ثنائي اللغة ضخم (`147,674+` مدخلاً)** | يضم الجذور اللغوية، والمشتقات الصرفية، والمتلازمات اللفظية، والتعابير الاصطلاحية (`Idioms`)، والأسماء الشخصية والجغرافية المركبة، ومئات المصطلحات الفلسفية والعلمية والطبية والقانونية ومصطلحات الذكاء الاصطناعي والأمن السيبراني |
| **بحث ذكي بالعربية والإنجليزية (بالتشكيل أو بدونه)** | يدعم التطبيع اللغوي الكامل للألف والهمزات والتاء المربوطة والياء، وتفكيك السوابق واللواحق، والبحث التقريبي لتصحيح الأخطاء الإملائية (`Fuzzy Matching`)، مع فهرس بحث فوري `SQLite FTS5` يستجيب في أقل من 5 أجزاء من الثانية |
| **نافذة الترجمة العائمة المتزامنة (`Always-On-Top Overlay`)** | تعمل فوق أي برنامج خارجي (متصفح، قارئ PDF، محرر نصوص، أو بيئة برمجة) عبر الاختصار العام `Ctrl+Shift+T` أو `Ctrl+Q` أو `Alt+Q`، وتلتقط النص المحدد تلقائياً وتترجمه محلياً بدون إنترنت أو سحابياً، مع مزامنة لحظية ثنائية الاتجاه (`/api/sync`) مع التطبيق الرئيسي |
| **استوديو المسح الضوئي البصري المزدوج للصور (`Visual OCR Studio`)** | يستخرج النصوص العربية والإنجليزية من الصور ولقطات الشاشة (`Ctrl+V`) محلياً عبر محرك `Windows.Media.Ocr` الأصلي ومحرك `Tesseract.js v5` المدمج (`ara.traineddata` + `eng.traineddata`) أو سحابياً، ويعرض الصورة الأصلية يميناً والصورة المترجمة يساراً مع إمكانية تظليل ونسخ النص مباشرة من داخل الصورتين وحفظ الصورة المترجمة بصيغة `PNG` |
| **نظام التعلم الذاتي المستمر (`Self-Learning Lexicon`)** | يتعلم التطبيق تلقائياً من كل ترجمة جديدة، مع زر مخصص («💾 حفظ في القاموس المحلي») لتثبيت أي مصطلح أو جملة بتعديلاتك الخاصة ومزامنتها فوراً بين التطبيق الرئيسي والنافذة العائمة |
| **نطق صوتي ذكي للعربية والإنجليزية (`Smart Hybrid TTS`)** | يدعم النطق باللهجتين الإنجليزية الأمريكية (`en-US`) والبريطانية (`en-GB`) عبر `Windows SAPI5` محلياً، ويشغّل القارئ الصوتي العربي الطبيعي تلقائياً عند الاتصال بالإنترنت لتعويض غياب القارئ العربي الافتراضي في ويندوز |
| **نظام البطاقات التعليمية والتكرار المتباعد (`SRS Flashcards`)** | يتيح حفظ المفردات في مجموعات مخصصة، ومراجعتها وفق خوارزمية التكرار المتباعد (`SM-2`)، وتصدير واستيراد قوائم المفردات بصيغتي `JSON` و `CSV` |
| **إدارة مثالية للعمليات وإيقاف تشغيل النظام (`Clean Lifecycle`)** | يعمل كنسخة واحدة فقط في النظام دون تراكم مهام خلفية في مدير المهام (`Task Manager`)، ويغلق مهمته تلقائياً عند إغلاق التطبيق أو عند إيقاف تشغيل ويندوز (`WM_QUERYENDSESSION`) دون إعاقة إيقاف الجهاز |

## اختصارات لوحة المفاتيح العامة (Global Keyboard Shortcuts)

* **`Ctrl + Shift + T` أو `Ctrl + Q` أو `Alt + Q`:** التقاط النص المظلل من أي نافذة نشطة في ويندوز وإظهار ترجمته الفورية في النافذة العائمة فوق جميع التطبيقات.
* **`Ctrl + C` (أثناء تفعيل المراقبة الذكية في النافذة العائمة):** ترجمة أي نص يتم نسخه في النظام تلقائياً وبسرعة فائقة.
* **`Ctrl + V` (داخل تبويب المسح الضوئي OCR):** لصق أي صورة أو لقطة شاشة مباشرة من الحافظة لمسحها ضوئياً وترجمتها فوق الصورة.
* **`Ctrl + Enter` (داخل محرر الترجمة الرئيسي):** تنفيذ الترجمة السياقية والمقارنة الفورية للنص المكتوب.

## البناء التلقائي والمحلي (Building from Source)

### 1. البناء التلقائي عبر GitHub Actions
يحتوي المستودع على ملف سير العمل الجاهز `.github/workflows/build-single-exe.yml`؛ وبمجرد دفع أي تعديل (`git push`)، يقوم خادم GitHub تلقائياً بـ:
1. فحص أمان الحزم والتأكد من خلوها من أي ثغرات أمنية (`0 Known Vulnerabilities`).
2. تضمين نماذج الـ OCR العربية والإنجليزية (`ara.traineddata` و `eng.traineddata`) ومكتبة `Tesseract.js v5.1.1` وفك ضغط قاعدة البيانات داخل حزمة `EmbeddedPayload.zip`.
3. ترجمة ودمج المشروع بالكامل عبر `.NET 8.0` و `Inno Setup` في ملف تنفيذي واحد مستقل ونشره تلقائياً في قسم **Releases**.

### 2. البناء المحلي الفوري على نظام ويندوز
يمكنك بناء الملف التنفيذي الموحد `LinguaDeskPro_SingleFile.exe` محلياً على جهازك في ثوانٍ دون الحاجة إلى تثبيت أي أدوات خارجية، وذلك بالضغط المزدوج على الملف:
```bat
BUILD_SINGLE_EXE_LOCALLY.bat
```
